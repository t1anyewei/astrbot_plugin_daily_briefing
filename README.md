# 每日群报时

面向 AstrBot `v4.26.8` 和 NapCat / OneBot v11 的 QQ 群日报插件。管理员可为任意群单独订阅，机器人每天在北京时间指定时刻主动发送当天日期、距离周末和下一法定节假日的倒计时。

## 安装与配置

1. 将本目录放入 `AstrBot/data/plugins/`，或推送至 Git 仓库后从插件市场安装。
2. 在 AstrBot WebUI 的插件配置中选择日报人格和聊天模型。未选择模型时，插件仍会按时发送事实版播报。
3. 打开插件详情页中的“法定节假日”页面，逐条添加假期名称、开始日期和结束日期。补班日无需填写；每年公布新安排后更新此列表。

## 法定节假日页面

在 AstrBot WebUI 的“插件”页点击“每日群报时”插件卡片，再打开“法定节假日”页面，即可维护放假安排。每条假期包含名称、开始日期和结束日期；保存后插件会自动将日期范围用于日报倒计时。

## 管理员指令

| 指令 | 用途 |
| --- | --- |
| `/订阅日报` | 为当前 OneBot QQ 群订阅每日播报 |
| `/取消订阅日报` | 取消当前群的订阅 |
| `/修改每日报时时间 07:00` | 修改所有订阅群的发送时间（北京时间） |
| `/每日播报状态` | 查看当前群订阅状态和配置摘要 |
| `/立即发送每日播报` | 向当前群发送一次测试日报 |

所有指令都只允许 AstrBot 管理员在 OneBot 群聊中使用。插件仅保存订阅群的 AstrBot 会话标识和群号，以及插件配置；不保存群消息或成员资料。
